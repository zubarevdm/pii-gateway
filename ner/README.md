# NER для детекции персональных данных

Слой 2 шлюза сейчас работает на Natasha. Здесь собираем размеченный датасет,
меряем текущий детектор шлюза (regex + контрольные суммы + Natasha) против LLM
и дообучаем собственную модель, которая заменит Natasha, если окажется лучше.

**Статус:** в работе. Схема сущностей и правила разметки лежат в [docs/annotation.md](docs/annotation.md).

## Состав

- `src/ru_pii_ner/generate.py` — синтетическая обучающая выборка по шаблонам.
- `src/ru_pii_ner/testset.py` — тестовый набор: черновики с инлайн-разметкой, экспорт в Label Studio.
- `data/test/drafts/` — черновики теста. Из шаблонов тест не собирается, иначе метрика покажет заучивание шаблонов.
