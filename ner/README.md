# ru-pii-ner

Распознавание персональных данных в русских текстах: размеченный датасет,
сравнение бейзлайнов (regex, natasha, LLM) и дообученная NER-модель
для [pii-gateway](https://github.com/zubarevdm/pii-gateway).

**Статус:** в работе. Схема сущностей и правила разметки лежат в [docs/annotation.md](docs/annotation.md).
